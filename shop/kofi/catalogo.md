# Ko-fi Shop — catálogo

Referência: [ko-fi.com/lelouchiee/shop](https://ko-fi.com/lelouchiee/shop)

- Tipo: **Digital item**
- Assets: `files/<slug>.pdf`
- Resgate: menu lateral → Loja do Apoiador → Resgatar
- Gerar PDFs: `VITE_SUPPORTER_HMAC_SECRET='…' npm run generate:kofi-shop`
- Gerar previews: `npm run generate:kofi-previews` → `previews/<slug>.png` (600×600)
